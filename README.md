# Bioinformatics Portfolio

This repository is the landing page for my job-relevant bioinformatics projects.

## Projects overview

| Project | Problem | Methods | Outputs | Skills |
|---|---|---|---|---|
| metabolomics-rt-matcher | Match LC-MS retention times to a reference library | Python, pandas, scoring/QC, classification | matched tables + QC plots | metabolomics, algorithm design, validation |
| rnaseq-differential-expression-pipeline | Identify DE genes between conditions | FastQC/MultiQC, alignment, counts, DE | DE table + volcano/heatmap | RNA-seq, statistics, reporting |
| ngs-variant-calling-mini-pipeline | Call + filter variants from NGS reads | BWA/samtools/Freebayes | VCF + filtered table | genomics pipelines, QC |
| proteomics-fdr-and-quant-workflow | Control false discoveries in proteomics | target-decoy FDR, BH correction | results tables + figures | proteomics, statistical rigour |
| hpc-nextflow-infrastructure | Reproducible workflow execution | SLURM, Nextflow, containers | runnable pipeline template | engineering, reproducibility |
